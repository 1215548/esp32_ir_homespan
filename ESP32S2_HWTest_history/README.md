# ESP32S2 硬件测试 · 历史版本（r9–r54）

LOLIN S2 MINI（ESP32-S2）Arduino 多文件程序的历史版本归档。主分支根目录只有 r1–r8 与当前版 r55；r9–r54 集中放在本文件夹，避免顶层被 46 个版本目录淹没。

## 目录结构

```
ESP32S2_HWTest_history/
README.md ← 本文件（各版功能说明）
ESP32S2_HWTest_r9/ ← 每个子目录就是一个完整的 Arduino 工程文件夹
ESP32S2_HWTest_r9.ino （文件夹名必须与.ino 文件名一致，Arduino 才认）
cn6.h （GB2312 16 点阵字库，各版相同）
ESP32S2_HWTest_r10/
...
```

## 文件状态

- 已收录：r9、r10、r11、r12、r13（真实快照，.ino 各不相同）。
- 待补：r14–r54（这批版本在作者工作机上曾共用一个目录、后续版本覆盖了旧文件，本地已无快照；需作者提供 Windows 上的各版拷贝补齐，补齐后放进同名子目录即可）。
- 字库说明：cn6.h 经 md5 核对，各版完全相同（b53c6294e1fff61c57e79860272b6ad0），待补版本可直接复用本文件夹里任一版的 cn6.h，无需另发。
- r55 不在本文件夹：它是当前版，已在主分支根目录（ESP32S2_HWTest_r55/）。

## 各版功能

- r9：四项硬件测试。KEY1/KEY2 改发正确 R05D（开机 B2 4D BF 40 D0 2F、关机 B2 4D 7B 84 E0 1F），KEY3/KEY4 保留 48 位老码对照；屏幕 2 秒循环颜色测试；按键值→LED1/LED2 二进制显示；红外接收显示在状态区 + 串口；自动发送已关闭。单文件 + 字库。
- r10：红外学习 + 原始数组回放。因构造发送的关机码无效，改走学习路线：KEY1 学习 A / KEY2 发射 A，KEY3 学习 B / KEY4 发射 B；学习后把抓到的原始时间数组原样 sendRaw 发出（R05D 199 项超 IRremote 100 项缓存，解码值不可靠）。单文件 + 字库。
- r11：基于 r9，串口输出详细红外解码。每次接收都在串口打印协议 / 数值 / 位数 / 原始时间数组（sendRaw 格式，可直接复制使用）；灯控第一步（先看清灯遥控的码）；发送同 r9。单文件 + 字库。
- r12：菜单版，灯控制。首次分出 codes.h（码表）+ ui.h（界面）：一级菜单灯 / 空调 / 红外解码 / 关于 / 返回；灯 9 个 NEC 键码（KEY2/KEY3 选码，KEY1 发送）；空调开关 R05D；解码页显示最近一次接收；关于页。
- r13：菜单版，加减键局部刷新。KEY2/KEY3 导航时只重画旧选中行与新选中行（首页按键只刷状态区第 1 行），不再全屏；状态切换、发送、清除仍走全屏。
- r14：菜单版，灯 / 空调子菜单显示解码键名（收到信号时按码表查键名显示，不只显示数值）。
- r15：红外测试菜单。3 秒开 / 3 秒关 38kHz 载波（RMT sendRaw），KEY1 开始 / 暂停，KEY4 返回并停止；用于手机摄像头验证发射管是否发光。
- r16：灯 / 空调发送与接收行改为局部刷新（不再全屏）。
- r17：空调码改为开机 B21FD8 / 关机 B27BE0（现行开机 / 关机码）。
- r18：空调子菜单 7 项（开关 / 温度± / 模式 / 风速±），状态跟踪（默认自动 / 26°C / 固定风 = B21FD8），按 pinaland 格式编码；中风 010 待实测。
- r19：8 个美的附加功能固定码（屏显切换、左右风开 / 关、上下风开 / 关、强劲开 / 关、模式；B9 首字节，照原样双帧发送，待实测空调认不认）。
- r20：空调页合并为 15 项滚动列表（7 行可见 + 滚动条），状态循环改名“模式循环”（与固定码“模式”区分）。
- r21：颜色常量修正。
- r22：WiFi 设置页 + 开放热点 AP ESP32S2-Setup（无密码、无 captive portal）+ 网页配网（SSID / 密码存 NVS wifi，试连 ≤10 秒，成功自动关热点；开机读 NVS 后台自动连接）。
- r23：首页三态（时钟 / 同步中 / Esp32-IR）+ NTP（北京时间）+ HomeSpan 在 WiFi 连上后自动启动（灯 + 空调 7 个瞬时开关 + 温度），按键 / 网页 / 家庭三路共用 act* 动作。
- r24：灯服务名修正（Service::LightBulb 大写 B；Category::Other）。
- r25：网页端口改 8080（HAP 占 80；裸 IP 空白是预期）。
- r26：服务显示名改 ConfiguredName（不是 Name）。
- r27：requestIr 签名改 uint8_t（避 Arduino 自动原型与自定 enum 冲突）。
- r28：HomeKit 瞬时按键弹回移出 update() 到 loop 统一处理（修警告 + 连发）；网页 / 家庭发送帧已验证，自收 UNKNOWN 为自身回波。
- r29：网页在热点开或 STA 连上时都跑；三个 Raw 发送前后关 / 开接收头（自收回波消失）；灯开关状态翻转。
- r30：lightIsOn 翻转从 sendLamp 移到灯页 KEY1 分发处。
- r31：WiFi 页 KEY4 不再关热点。
- r32：网页 / 家庭红外改 8 槽 FIFO 排队 + 500ms 静默延迟（按键即时不走队列）+ webEnabled 总开关（仅 RAM，重启默认开）。
- r33：首页时钟局部刷新；WiFi 页 KEY1=网页 / KEY2=热点；网页控制与配置合并根页（/wifi 302 回根页）；requestIr 排队去重。
- r34：纯编译修复（fillRect 补第 5 参）。
- r35：KEY1 改走 setWebEnabled（关时 close()+stop()，开时 begin()）；FreeRTOS 分任务暂缓。
- r36：HomeKit 空调 4 按钮改纯汉字（温度加 / 温度减 / 风速加 / 风速减；刷机后须移除配件重加 iOS 才读新名）。
- r37：WiFi 页自动刷新。
- r38：I2C 寻址真实扫描（SDA IO33、SCL IO35，0x08–0x77 写探查 ACK，屏显总数 + 每行一地址，最多 8 行，需外部上拉）。
- r39：BMP085（0x77）上首页（温度 0.1°C + 气压 0.1hPa，Wire 直读 Bosch 定点算法，无新库；未连接显示“未连接”，每周期重初始化可热插拔）。
- r40：红外复制（10 编号，NVS ircopy，KEY3 选编号、KEY2 发射、KEY1 学习 / 存储、KEY4 回菜单取消学习；发射 NEC / COOLIX，其它协议只显示；网页命名表单 POST /ircopy_name）。
